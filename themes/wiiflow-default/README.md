# WiiFlow Default

Separate ThemeHub frame theme based on stock WiiFlow Lite Default. Original background, font, normal/selected disc, favorites and settings icons come from https://github.com/Fledge68/WiiFlow_Lite/tree/master/out/imgs . Coverflow uses source/menu/menu.cpp default side angles (+70/-70 degrees) and .35 spacing, adapted to this browser renderer. Assets remain credited to WiiFlow contributors. This is a local recreation, not a Wii binary or pixel-identical GX port.

Left/right or wheel browses; Enter selects and then launches. F rotates the selected case. Escape returns. Down reveals controls. Pointer near the top/bottom reveals controls. Logos: Original/Flattened toggles spine style and saves via ThemeHub. Backs use one artwork image and generated packaging details. Steam Deck hardware testing remains required.
