# Additional classic pages

The added pages are part of the installed frame theme, not only browser-preview overlays.

| Page | How to reach it | Data/actions |
| --- | --- | --- |
| Game details | Any library/home game cover | Real library artwork, playtime, last played, launch, native game page; tiled shortcuts |
| Store | Home → Store | Featured listing, section tabs, search, game prices |
| Store product | Store cover; game detail → Store page | Description/screenshots via storeDetails; checkout opens Steam Store without purchasing |
| Community / friends | Home → Community / Chat | Friend names, online status and current game |
| Chat | Friend card | Real chat hands off to Steam; preview conversation stays local |
| Profile | Home profile badge; friends → My profile | Name and library count, library/friend shortcuts |
| Settings | Header gear | Classic grouped three-column settings menu |
| Interface preferences | Settings → Interface / Interface sounds | Host-supported animations, clock, sounds, TV mode, SFX/music volume |
| Downloads | Header download icon; library → Downloads | Current queue, progress/bytes/rate, pause/resume, manual refresh |
| Controllers | Settings → Add / Test | Browser-visible connected controllers, native Steam configuration handoff |
| Web favorites | Home → Web | Favorite shortcuts; native menu handoff for external browsing |
| Screenshots / videos | Library → Videos; game details → Screenshots | First host media batch; still-image viewer; native video player |
| Local Music | Library → Local Music | Album and track selection; play/pause/previous/next through host audio service |
| Power | Header power icon | Return home/Steam and native power chooser; no immediate shutdown action |

These references span different classic Big Picture revisions. The pages adapt those layouts to the available ThemeHub services; they do not claim to be exact historical screen restorations. The old download image linked from the 2015 article returned HTTP 503. Downloads, controller overview, profile, web favorites, media/music and power therefore use the shared classic visual language. No modern Steam Deck screenshot was used as an old-interface reference.

Achievements, news, DLC, cloud sync, badges and community posts are not exposed by this bridge. The theme does not invent those values; corresponding tiles open Steam's native game or friends interfaces. Browser-based previews simulate all host operations. Real controller handling, Steam service responses, audio and suspend/wake need Steam Deck testing.
