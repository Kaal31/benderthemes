# Kinect dashboard page pass

Reference: the user-supplied “Kinect NXE Dash online on xbox 360 in 2025” video (65.74 seconds), sampled throughout its duration in `preview/kinect-video-overview.jpg`, plus decoded ReLive Kinect scenes. The video shows a tall profile pane, centered sign-in/Guide overlays over a dimmed dashboard, an expanded information card and horizontal dashboard navigation. It does not show every library/settings page or every complete enter/exit transition.

Implemented separate profile, information, library and dialog treatments. Profile has an orange identity strip and action list with the avatar standing beside it. Welcome’s Steam Store card expands into an information card. Library/settings/media/service pages share existing live data and actions with the NXE implementation but use scoped light Kinect presentation, green focus, Kinect button artwork and Kinect transition rules. Power and Options keep the dashboard underneath a dimmed overlay. Full pages hide dashboard cards, labels and duplicate hints; closing restores the original selected card. Avatar editing retains its separate existing editor and legacy fallback.

Every primary card destination now opens an in-theme page before any explicitly selected Steam/system action, except the explicit Home action. Music, videos, pictures, library, achievements, friends, messages, downloads, store, browser, community, dashboard choice and home preferences are connected. Existing service/Steam actions remain functional. The local media data/player implementations are shared. The optional original artwork pack remains optional; new styling and fallback information artwork are authored locally.

The omitted aura-floor layer is now rendered from the optional Kinect pack, with an authored fallback. Shared NXE artwork/motion helpers use an era context: default NXE behavior remains unchanged. Kinect suppresses the NXE corner wordmark and requests Kinect button artwork.

Motion uses separate slide/fade and small dialog scale/fade treatments. Durations (220 ms entry, 160 ms exit) are approximations, not recovered stock timelines. Library layouts reuse established page geometry and are not claimed as frame-exact Kinect reproductions; the supplied clip does not establish those layouts. The information card content is a Steam adaptation of the reference’s expanded card, not a fictional Xbox service.

Validation: TypeScript, browser checks for library/media/settings/dashboard/power/profile enter/back flows, expanded information/Guide/reduced-motion flows, no browser errors. Screenshots: `preview/kinect-page-*.png`. Interactive preview: `preview/x360-kinect-pages.html?theme=x360&xs=kinect&consoleArt=1`.

Home/avatar pass: Home and Home Screen cards use an independently drawn flat house pictogram. My Avatar now selects a Kinect-specific variant of the shared editor, with a green/grey floor, light flat action panel, straight category/item grid, scoped entry/reduced-motion behavior and no duplicate root heading. NXE and Metro retain their own variants. Verified root-to-style navigation, Back hierarchy, loaded avatar library, icon presence and browser errors. This editor presentation is a Kinect-era adaptation; the supplied 65-second clip does not show the complete clothing editor. Preview: `preview/x360-kinect-avatar-window.html`.
