# Blades reference pass

ReLive Beta2 provides 73 decoded Blades override scenes (Guide, profile, media and dialogs), plus separately supplied artwork. Its MC360-style customization is not a complete stock dashboard layout. Our existing supplied videos show NXE, Kinect and Metro, not Blades.

DashX360 is a secondary recreation reference. The inspected local source is pinned to `0c8adb2cef4ad7dff2bf889351efa1f1c244aef2`. `BladesArtworkHost.cs` uses a 0.200-second ease-out slide and a 1920×1080 design surface. We adapt its motion duration independently; we do not copy its source or assert that this timing is recovered console behavior.

This pass connects the Theme Hub banner and bottom game tray to the vertical controller focus path, retains focus per blade, uses the optional pack's existing focused disc-tray texture, and supplies an independently authored fallback focus texture. Blade tabs, active edge, page clipping now share the same 200 ms easing. Reduced-motion preference disables these effects. Rows reserve space above the bottom tray on shorter screens.

The translucent whitewash footer overlay remains part of the optional artwork pack. No extracted artwork has been newly added to the theme bundle. Theme Hub artwork remains independently authored.

Validation: TypeScript check, browser controller navigation in both artwork modes, blade focus memory, short-screen row clearance, reduced-motion behavior and browser error checks. Preview: `preview/x360-blades-continuous.html?theme=x360&xs=blades&consoleArt=1`.

Continuity correction: memoize the merged asset map so ordinary selection/page changes do not restart the background frame loop. Keep the content wrapper mounted and remove its separate keyed entrance animation; the blade shell provides the movement. Browser regression checks confirm persistent content/canvas nodes and background frame progression during rapid page changes in both artwork modes.

Settling correction: blade chrome changes visibility without an opacity crossfade. Background clip/canvas retain composited layers before and after motion, and alternate background/chrome textures are decoded ahead of navigation. The background-only settled-frame comparison (with atmosphere frozen) matches within 1/255 at 300 and 600 ms; remote game art can load separately. Preview: `preview/x360-blades-steady.html`.

Screenshot (115) overlay pass: independently drawn CSS header/footer bands replace the narrow segmented MC360 whitewash overlay in the dashboard. Header occupies 13% of the stage height, footer 16%, with rounded inner corners and translucent shading. Both follow the content column during the blade slide; the disc tray now clears the footer. This is a visual approximation from the photographed console reference, not recovered scene geometry. All five blades were checked in both artwork modes for overlay/profile/tray clearance and browser errors. Preview: `preview/x360-blades-reference-glass.html`.

Overlay refinement: replace the detached rounded-panel appearance with strips reaching beneath the chrome. Reduce corner radii and header darkness, lighten the footer toward its bottom, and use thin translucent separator edges. Header/footer heights are 12.5%/14.5% of the stage. Visual comparison and tray-clearance checks cover all five blades. Latest preview: `preview/x360-blades-glass-refined.html`.

Center-wash correction supersedes the CSS dark-band experiments: use the optional pack’s existing background-overlay-whitewash-left/centertile/right-ws textures over the complete background. These produce the pale central sheet and curved cutouts that expose the original header/footer color. Independently authored SVG equivalents supply the fallback. No new original artwork is bundled. Typecheck and image loading checks pass in both modes. Latest preview: `preview/x360-blades-center-wash.html`.

Padding/motion correction: all left-side layout anchors now inherit one registered animated CSS length, keeping the profile, active trim and glass at constant offsets during navigation. The glass is rendered as one sheet with mirrored cap sampling, adjusted along the full opposing metal outline to preserve the left-side visible inset. Animation-frame regression checks cover both directions through Games, Media, System and Live. Latest preview: `preview/x360-blades-padding-motion.html`.

The center wash uses the existing tile color/alpha, preserves a narrow side strip and follows the trim curve. Header/footer turn toward the trim rather than forming detached rounded panels. Validated on the Games blade and with the bidirectional animation-frame regression test; typecheck passes. Latest preview: `preview/x360-blades-reference-corners.html`.

Left endpoint spine correction: the left outer runner now remains behind the page fill (the right runner remains above it). This removes the gray/color split under Marketplace’s vertical label. The selected label moves 6 design pixels left and slightly down into the colored tab recess. Browser checks cover label bounds across all five blades in both artwork modes. Latest preview: `preview/x360-blades-market-spine.html`.

Blade sweep pass: retain a snapshot of the outgoing page (including canvas pixels) under the traveling opaque blade, with a directional moving clip. Forward navigation brings the incoming blade from the right stack; reverse navigation sends the outgoing blade back to that stack. No opacity crossfade is used. Snapshots/animations are canceled and removed on interruption/unmount; reduced-motion navigation skips them. DashX360 remains the secondary behavior/timing reference, not proof of stock-console timing. Browser checks cover both directions, multi-blade jumps, outgoing-page retention, movement distance, cleanup and reduced motion. Preview: `preview/x360-blades-sweep.html`.
