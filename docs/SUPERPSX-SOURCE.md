# SuperPSX PS4 source

Discover → PS4 lists the live public SuperPSX ps4_themes.json catalog with previews, search and pagination. Catalog verified 2026-11-14: 957 entries / 40 Hub pages. Only validated HTTPS VikingFile and 1fichier links are offered as external download pages. No themes are bundled.

These downloads are external RAR/PKG packages, not direct importer-ready files. Our PS4 reader supports extracted theme.xml folders and ZIP/RAR archives containing that descriptor; encrypted PKGs are unsupported. The Hub explains this and does not offer a false direct-import action.

Sample download attempt: first catalog entry, Neptunia VII Lastation theme, 12.31 MB RAR. VikingFile redirected to vik1ngfile.site and required a Cloudflare Turnstile challenge. Its 1fichier mirror returned a Welcome page without a file download. No sample package was retrieved, so package compatibility remains unverified.
