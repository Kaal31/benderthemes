# Onyx Wheel

A separate black iPod-inspired look sharing Silver's stationary touch-wheel implementation. Circular pad input and mouse scrolling browse game covers or the active page's items. MENU cycles Now Playing, Games, Library, Discover and More. Center activates the selected item. On Now Playing rotation seeks by five seconds per detent; side buttons skip tracks and center/play toggles playback. The full music page suppresses the shared floating player.

Visual settings preserve portrait covers, square capsules and classic Cover Flow, with independent off/clear/prismatic glass choices for the display and covers. Reduced motion and the animation setting are respected. Silver retains its separate tilted-metal-floor / shadows-only setting.

The browser toolbar exposes the visual options, animation toggle, SFX toggle, volume and a sound test. Real Steam artwork and generated test albums are preview-only fixtures. Run `node onyx-check.mjs` to rebuild both previews and check Onyx's page navigation, settings and music behavior.

The local Onyx iPod SFX pack maps rotation, wheel presses and page switches separately. SOURCES.json records the user-provided spin clip and downloaded public preview sources. This is a personal test pack; source licensing must be resolved before public redistribution.
