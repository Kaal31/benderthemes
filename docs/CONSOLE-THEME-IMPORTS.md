# WiiFlow downloads and Wii U theme files

WiiFlow's source links open the original author's download page. ThemeHub watches Downloads while the themed home or its Theme files tab is open. It ignores browser partial-file extensions, waits for a stable completed file, converts every theme INI in ZIPs or extracted folders, and installs checked ThemeHub packages under distinct content-derived IDs. RAR/7z use the system libarchive when available; otherwise the status asks the user to extract into Downloads. Existing source archives are retained. Failed conversions show a reason and retry after a delay rather than reporting a false successful install. The manual Add a theme action also recognizes a raw WiiFlow ZIP.

The converter is now a runtime Python module; its CLI imports that same implementation. Shared WiiFlow renderer assets are obtained from the existing verified media pack and included in each local conversion. The Hub continues watching while the user visits an author's page. A visible Show more button above the source grid and the existing last grid card both append the next page. Partial live GBAtemp listings are merged with the saved index so an unavailable thread cannot hide the saved entries. The saved index has 66 entries, including separately credited Rhapsodii / Rhapsodii Shima and named BCT pack variants with original author links. Shared pack variants point to their common author page rather than pretending to be independent file downloads.

Wii U .utheme files contain patches, not complete replacement menu artwork. Applying those patches requires the user's matching Wii U menu files. Missing stock, mismatched versions and unreadable artwork are now reported on the selected home instead of silently presenting the default appearance with a custom name. The notice offers Import Wii U menu files. Automatic Downloads/SD discovery repeats while the Wii U theme is open; importing menu files invalidates cached theme artwork and refreshes presets. A complete .utheme import still preserves creator metadata and uses the existing checksummed patch reader. No Nintendo menu data is shipped by these changes.

Validation covers real runtime conversion and installation of multi-theme archives, manual raw ZIP import, partial/renamed/completed downloads, extracted folders, deduplicated imports, archive path/link limits, source pagination, late source response isolation, preset artwork application and an import prompt for a dump arriving after opening Wii U. System-libarchive checks are conditional on that library being installed; the current Windows environment does not provide it.
